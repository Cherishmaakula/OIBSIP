# Java Internship Projects

This repository contains two Java-based console applications developed as part of internship tasks.

---

## 🔹 Task 2: Number Guessing Game

### 📌 Description
This is a simple Java console application where the system generates a random number between 1 and 100. The user tries to guess the number. The program provides hints whether the guess is too high or too low and continues until the correct number is guessed.

### 🚀 Features
- Random number generation
- User input handling
- High/Low hints
- Attempt counter
- Replay option (play again)

### ▶️ How to Run
1. Open `NumberGuessingGame.java`
2. Compile and run the program
3. Enter guesses until you find the correct number

---

## 🔹 Task 3: ATM Interface

### 📌 Description
This is a Java console-based ATM simulation system that allows users to perform basic banking operations such as checking balance, depositing money, withdrawing money, and viewing transaction history after entering a valid PIN.

### 🚀 Features
- Secure PIN login
- Check account balance
- Deposit money
- Withdraw money with balance validation
- Transaction history tracking
- Menu-driven interface

### ▶️ How to Run
1. Open `ATM.java`
2. Compile and run the program
3. Enter PIN (default: 1234)
4. Choose operations from menu
